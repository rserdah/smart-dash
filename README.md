# Smart Home Generative UI Dashboard
An AI-powered smart home dashboard using Home Assistant that takes user prompts to execute actions on smart devices and generate resulting UI for further information or human control.

## Features
- **Generative UI Rendering:** Dynamically streams context-aware UI widgets generated by Gemini based on user requests.
- **Structured Tool Execution:** Uses Zod schemas to validate model outputs before triggering smart home controls or local database operations.
- **State & Query Caching:** Leverages TanStack Query for efficient server-state management and UI synchronization.

## Feature Roadmap
- **Home Assistant Integration:** Local device control and real-time state monitoring via local backend APIs and Prisma ORM.

## Tech Stack
- **Frontend:** React, TypeScript, Electron, TanStack Query
- **AI & Logic:** Vercel SDK, Gemini API, Zod Schema Validation
- **Backend & Database:** Node.js, Prisma ORM
- **Integrations:** Home Assistant REST API
